# Therapist Joy Site

This Vite React app powers the homepage and services pages for the therapist website.

## Build

Run:

```bash
npm install
npm run build
```

The production files are generated in the `dist/` folder.

## Deployment

The site is configured for a static host with a root base path. If you deploy to GitHub Pages or another static host, publish the contents of the `dist/` folder.
